# Task 01 - Temperature Converter

A Python program that converts temperatures between Celsius, Fahrenheit, and Kelvin scales.

## Features

- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Celsius to Kelvin
- Kelvin to Celsius
- Celsius to Celsius
- Fahrenheit to Fahrenheit
- Kelvin to Kelvin
- Handles invalid unit input
- Handles invalid numerical input

## Technologies Used

- Python 3

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository.
3. Open the project folder in the terminal.
4. Run:

```bash
python temperature_converter.py
